# Mohanraj S — Portfolio Website

## Files
- index.html — portfolio content and structure
- style.css — responsive modern styling
- script.js — mobile menu, theme toggle, reveal animations and contact form

## Before publishing
1. Replace `your.email@example.com` in `index.html` and `script.js` with your real email.
2. Replace the GitHub and LinkedIn placeholder links with your profiles.
3. Add your real resume as `assets/resume.pdf`.
4. Update education college/year if you want those displayed.
5. Add GitHub/demo links to each project if available.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
Create a GitHub repository, upload these files to the repository root, then enable GitHub Pages from the repository settings.
